MC下载器

版本 v1.1。一个用来下载 Minecraft 游戏文件的 Windows 小工具，单个 exe，不用安装。

下载 MC下载器.exe
约 6 MB / Windows 7 及以上 / 与 PCL 启动器配套使用

为什么做这个

PCL 新版关掉了自带的下载渠道，官方源在国内又经常慢得没法用。这个工具把几个镜像源都接上了，下载前先测个速，挑最快的那个下。

另外大文件会切成几块同时下，断了能接着传，下完校验 SHA1。装 Fabric、Quilt、Forge、NeoForge 这些运行器也不用再单独跑安装器，选好版本点一下就行。

怎么用

  1. 把 MC下载器.exe 放到 PCL 启动器所在的文件夹里，跟 Plain Craft Launcher.exe 放一起。
  2. 双击打开。游戏目录默认就是同目录下的 .minecraft，一般不用改。
  3. 点右上角的「获取版本列表」，等它加载完。
  4. 在左边列表里挑一个版本。想装模组加载器的话，右边「运行器」里选一个，版本列表会自动跟着你选的游戏版本变。
  5. 点「开始下载」。下载过程中可以暂停，也可以取消。
  6. 下完了打开 PCL，版本列表里就能看到，直接启动。

设置

界面上留了几个参数，一般不用动：

  • 并发线程数：默认 32。网好可以往上调，网差就调小一点。
  • 超时：单个连接等多久算超时，默认 30 秒。
  • 重试次数：一个文件下失败了重试几次，默认 3 次。
  • 限速：单位 KB/s，填 0 就是不限速。
  • 显示快照与远古版：勾上以后列表里才能看到快照版和老版本的 Alpha/Beta。

配置存在同目录的 MCDL-Settings.ini 里。想恢复默认，把这个文件删掉或者点界面上的「恢复默认」都行。

常见情况

  • 下得很慢：点一下「测速」重新选源，或者把线程数调大。
  • 中途失败了：换一个源再点「开始下载」，已经下好的文件会跳过，只补缺的。
  • 下完 PCL 里看不到：确认游戏目录选的是 PCL 用的那个 .minecraft，不是别的地方。
  • 同名版本：默认会建一个独立的隔离目录，不会覆盖你已有版本。
